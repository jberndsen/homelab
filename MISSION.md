# Mission: Homelab monitoring

## Why
Learn Prometheus and Grafana by deploying monitoring for the K3s VM and media
workloads, then use evidence to understand resource use and workload health.

## Success looks like
- Trace a metric from its endpoint through Prometheus to a Grafana panel.
- Explain object state versus resource consumption and missing data.
- Reproduce and operate the stack through Git and Argo while preserving media data.

## Constraints
- Follow plans/monitoring-plan.md, one lesson at a time with owner checkpoints.
- Use explicit manifests, pinned images, local storage and the agreed budget.

## Out of scope
Notifications, logs, tracing and device exporters in the initial lessons.
